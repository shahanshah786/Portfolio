About

A quick introduction

The person behind the code — background, focus areas, and how I like to work.

I'm MD Shahnshah, a software engineer and full-stack developer based in Noida, India, with close to 6 months of hands-on, real-world experience building responsive web applications using PHP, ReactJS, JavaScript, Tailwind CSS and MySQL. My work spans the entire product lifecycle — from designing database schemas and writing backend logic, to building clean, user-friendly interfaces on the frontend.

During my internship at Sewacity.com, I engineered 4+ responsive web features, integrated 3 third-party APIs that cut manual data-entry work by roughly 30%, and delivered client-facing projects on schedule with zero missed deadlines — a track record I'm proud of and continue to build on. I also debugged and resolved recurring production issues, which taught me a lot about writing maintainable, dependable code rather than just "code that works once."

Beyond web development, I have a strong foundation in Data Structures & Algorithms, Java, C and C++, built through my BCA coursework and reinforced through independent projects like a full-stack Crime Data Management System (Java, Servlets, JSP, MySQL, deployed on Apache Tomcat) and a Criminal Face Detection system that combines computer vision with a practical, real-world use case.

I'm also the developer behind KhetGuru AI, an Android smart-farming assistant built with Java, Firebase and Google Gemini AI, designed to help farmers get AI-powered crop guidance, weather forecasts and market prices in their own language — a project that pushed me to work with speech recognition, real-time databases and AI APIs in a mobile context.

Right now, I'm actively researching and building in Data Science — currently working through data visualization, and steadily moving toward applied machine learning. I like to treat every new project as a chance to go one level deeper: understand the "why" behind a tool, not just the "how."

Along the way, I've earned certificates and recognitions in JavaScript, PHP & MySQL, Web Development, Cybersecurity, LibreOffice, and IoT — alongside real project delivery experience at Sewacity.com, all of which I've documented on my Certificates and Achievements pages.

I care about writing clean, readable code, shipping things that actually work for real users, and staying curious enough to keep learning outside my comfort zone — right now, that means data science and AI. If you're looking for someone who can take a project from database schema to deployed product, and who's genuinely excited about the next thing to learn, let's talk.
