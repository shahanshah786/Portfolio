KhetGuru AI – Smart Farming Assistant

KhetGuru AI is a comprehensive Android application designed to support farmers with modern technology and Artificial Intelligence. The application was developed to simplify farming-related decision-making by providing crop guidance, weather updates, market information, and AI-powered assistance through a single platform.

Project Objective

The main objective of KhetGuru AI is to bridge the gap between farmers and technology by providing real-time agricultural information, crop recommendations, weather forecasts, and intelligent support in local languages. The application enables farmers to access important farming services directly from their smartphones.

Architecture & Development Process

The application was developed using Android Studio with Java as the primary programming language. XML was used to create responsive user interfaces. The app follows a modular structure where different functionalities such as Weather, Market, Profile, and AI Assistant are managed through separate Fragments.

Firebase Authentication was integrated to allow secure login using mobile number OTP verification. User information is stored and synchronized using Firebase Firestore and Realtime Database. Firebase Storage is used to store profile images and agricultural-related media files.

For AI functionality, Google Gemini API was integrated to create "AskGuru," an intelligent farming assistant capable of answering agriculture-related questions, providing crop guidance, and assisting farmers in multiple languages.

Weather information is fetched through OpenWeather API, providing real-time weather conditions and forecasts. Voice-based interaction is enabled using Android Speech Recognition and Text-to-Speech APIs, allowing farmers to communicate with the AI assistant using voice commands.
